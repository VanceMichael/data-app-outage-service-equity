# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## connections

户表与馈线、服务类别的有效区间。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 接线段 |
| `household` | string | 匿名户 |
| `feeder` | string | 馈线 |
| `start` | integer | 起分钟 |
| `end` | integer | 止分钟 |
| `service_class` | string | 服务类别 |

## plans

计划及通知范围；收到通知的户不随接线迁移自动增加。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 计划 |
| `feeder` | string | 馈线 |
| `start` | integer | 起分钟 |
| `end` | integer | 止分钟 |
| `notified` | array | 已有效通知户 |
| `state` | string | 已通知或撤销 |

## switch_events

开关实际影响与计划独立存在。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 事件 |
| `feeder` | string | 馈线 |
| `start` | integer | 失电起 |
| `end` | integer | 恢复止 |
| `kind` | string | 故障或计划 |

## meter_reports

户表可核实窗口；空缺不是供电证据。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 回报 |
| `household` | string | 匿名户 |
| `start` | integer | 起 |
| `end` | integer | 止 |
| `state` | string | 供电或失电或缺报 |

用户异议及裁定记录。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 异议 |
| `household` | string | 户 |
| `event` | string | 事件 |
| `finding` | string | 裁定 |
| `known_day` | integer | 获知日序 |

## payments

已发补偿，金额分。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 支付 |
| `household` | string | 户 |
| `period` | string | 所属期 |
| `amount_cents` | integer | 金额 |
| `paid_day` | integer | 支付日序 |

## transfer_windows

备选转供有效窗口及负担人数上限。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 转供 |
| `from_feeder` | string | 原馈线 |
| `to_feeder` | string | 目标 |
| `start` | integer | 起 |
| `end` | integer | 止 |
| `max_households` | integer | 最大转供户 |

## rules

每户补偿及轮停保护合同。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 服务类别 |
| `max_continuous_minutes` | integer | 连续中断上限 |
| `free_planned_minutes` | integer | 有效通知计划豁免 |
| `rate_cents_per_minute` | integer | 每分钟分 |
| `notice_lead_minutes` | integer | 通知提前量 |
